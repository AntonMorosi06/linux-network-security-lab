# Safe Use Policy

This repository is for defensive, educational, and local laboratory use only.

Allowed environments:

- localhost
- personal Linux machines
- virtual machines
- containers
- network namespaces
- local isolated labs
- explicitly authorized systems

Not allowed:

- scanning public IP ranges without authorization
- testing university or company networks without permission
- probing third-party services
- collecting traffic from networks that are not yours
- bypassing access controls
- attempting exploitation

The goal of this repository is to learn Linux, networking, diagnostics, observability, automation, and defensive security.
