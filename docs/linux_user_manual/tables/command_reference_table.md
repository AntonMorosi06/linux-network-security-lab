# Compact Command Reference Table

| Category | Commands |
|---|---|
| Identity | `whoami`, `id`, `groups`, `hostname` |
| System | `uname -a`, `date`, `uptime`, `df -h`, `du -sh` |
| Files | `pwd`, `ls`, `cd`, `find`, `tree`, `cat`, `less` |
| Text | `grep`, `awk`, `sed`, `head`, `tail`, `sort`, `uniq` |
| Permissions | `chmod`, `chown`, `umask` |
| Processes | `ps`, `top`, `pgrep`, `kill` |
| Networking | `ip addr`, `ip route`, `ping`, `curl`, `ss`, `lsof` |
| DNS | `dig`, `nslookup` |
| Logs | `journalctl`, `dmesg`, `tail -f` |
| Docker | `docker ps`, `docker logs`, `docker inspect`, `docker compose` |
| Git | `git status`, `git add`, `git commit`, `git push` |
