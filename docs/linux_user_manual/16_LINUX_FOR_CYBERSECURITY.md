# Linux for Cybersecurity

Linux is important in cybersecurity because many servers, cloud systems, containers, security tools and monitoring systems run on Linux.

## Key skill areas

```text
filesystem navigation
permissions
process inspection
network inspection
log analysis
service management
shell scripting
container diagnostics
safe evidence collection
```

## Defensive workflow

observe

test locally

interpret findings
write report
clean up
