# Publication Checklist

## Required before public release

- README reviewed.
- Lab index complete.
- CHANGELOG present.
- VERSION present.
- Release notes present.
- Safe-use policy present.
- Threat model present.
- Hardening checklist present.
- Risk register present.
- CI workflow present.
- Local CI validation passes.
- No real secrets committed.
- Generated reports reviewed.
- Private paths reviewed.
- Docker labs tested where possible.
- Screenshots reviewed before upload.

## Optional improvements

- Add repository topics on GitHub.
- Add screenshots.
- Add architecture diagram.
- Add release tag.
- Add GitHub release.
- Add badges to README.
- Add issue milestones.
