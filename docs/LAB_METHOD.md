# Laboratory Method

Every lab in this repository should follow the same structure.

## Objective

Explain what the lab is trying to demonstrate.

## Theory

Describe the technical concept behind the lab.

## Commands

Provide the exact commands used.

## Command description

Explain what each command does.

## Expected output

Show realistic examples of expected terminal output.

## Interpretation

Explain how to read the result.

## Common issues

Document common problems such as missing packages, permission errors, busy ports, DNS failures, firewall blocks, or commands that remain active.

## Cleanup

Explain how to stop services, remove temporary resources, and restore the system to a clean state.

## Security note

Explain why the lab is safe and what boundaries must not be crossed.
