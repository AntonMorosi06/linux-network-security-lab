# Releases

This folder contains curated release notes for the `linux-network-security-lab` repository. Release notes summarize the status of the project at a stable milestone and are intended for GitHub review, portfolio presentation and future version tracking.

## Available releases

| Release | File | Summary |
|---|---|---|
| v1.0 | `LINUX_NETWORK_SECURITY_LAB_v1_0_RELEASE_NOTES.md` | Complete local defensive Linux, networking and cybersecurity lab with 20 labs, full Linux User Manual and visual assets |

## Release policy

A release note should describe what is complete, what evidence exists, what the safety boundaries are, what skills are demonstrated and what future improvements remain. Release notes should not contain private logs, secrets, credentials or uncontrolled data.
