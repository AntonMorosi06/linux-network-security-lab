## Release Body

Linux Network Security Lab v1.1 — Safe Tools Expansion

This release expands the local defensive Linux and networking lab with a safe tool-awareness track.

The repository now documents 30 staged labs covering Linux diagnostics, networking, logs, local services, firewall concepts, packet analysis, monitoring, incident-response-style documentation, evidence handling and safe security-tool awareness.

All exercises remain local, defensive and authorized. Public evidence is sanitized and supported by evidence review, safety review, command-index review, release-readiness review and portfolio-publication review.

## Safety boundary

This release is designed for:

- localhost;
- personal machines;
- virtual machines;
- containers;
- Linux network namespaces;
- synthetic data;
- explicitly authorized lab environments.

This repository is not an offensive toolkit, not a production SOC, not an enterprise monitoring system and not a guarantee of system security.
