# Portfolio Summary

## Project title

Linux Network Security Lab

## One-line description

A defensive local lab repository for Linux diagnostics, networking, containerized services, API security, monitoring, CI and threat modeling.

## Extended description

This project is a structured hands-on repository designed to demonstrate practical Linux, networking and defensive cybersecurity skills in a safe local environment. It progresses from basic system diagnostics to network namespaces, firewalling, NAT, traffic shaping, API security, Docker networking, Docker Compose, Prometheus metrics, CI validation, threat modeling and a final capstone secure local service.
